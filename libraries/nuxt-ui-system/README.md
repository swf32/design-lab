# Nuxt UI System

This Library is Design Lab's first committed real-world Vue runtime fixture. Its Components are
small Vue SFC wrappers around [Nuxt UI](https://ui.nuxt.com/) and run through the Library's own
Vite config, Vue plugin, package environment, tokens, Stories, and Playgrounds.

It is intentionally not a copied component library. Nuxt UI remains an npm dependency under its
MIT license; the adjacent Design Lab manifests, previews, Stories, and draft Playgrounds are
authored integration examples.

The fixture proves Component discovery, catalog preview, production Playground controls, separate
draft Playground, Story rendering, light/dark token modes, HMR, and preview/Story capture. It does
not claim complete Vue parity: events/state telemetry, deep Inspector, canonical Vue usage source,
font/asset browser assertions, and Vue Wireframe/Page rendering remain explicit follow-up work.
