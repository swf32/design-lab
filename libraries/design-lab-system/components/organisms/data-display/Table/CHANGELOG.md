# Changelog

## 0.2.0 — 2026-07-26

- Added: column width, minimum, maximum, and resizable column contracts.
- Added: pointer and keyboard column resizing that redistributes adjacent widths without changing the table footprint.
- Added: optional width-change snapshots for application persistence plus authored-width reset by double-click or Home.
- Added: optional quiet zebra striping for dense registries without weakening hover or selection.
- Accessibility: resize dividers are focusable buttons with explicit labels, keyboard steps, and visible focus treatment.

## 0.1.0 — 2026-07-23

- Added: generic typed columns, arbitrary cell content, stable ascending/descending sorting, controlled and uncontrolled sort state.
- Added: comfortable and compact densities plus selected, empty, hover, focus, and sorted states.
- Accessibility: uses native table structure, column sort state, labelled grid semantics, and keyboard row activation.
